# Indicaciones HUAP

App web instalable (PWA) para generar las indicaciones médicas del Servicio de Urgencia y exportar el Word en el formato institucional.

- Funciona sin conexión una vez abierta.
- Los pacientes y paquetes de tratamiento se guardan solo en el dispositivo de quien la usa. No hay servidor ni base de datos.
- Instalación: Android (Chrome) menú ⋮ > Instalar aplicación; iPhone (Safari) Compartir > Agregar a pantalla de inicio.
